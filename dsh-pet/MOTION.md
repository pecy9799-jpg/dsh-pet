# 桌面抛掷动作 Windows 正式版

此包为基于 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的非官方改版，版本 `1.0.1`。上游基线为 `0.3.8`，提交 `c696095c5786e0eeb25fec0f37a9cdcf30059151`。

`1.0.1` 是本 Fork 的独立正式编号，在 `1.0.0` 正式版基础上修正恢复末段的人物形状，保留原动作时序和物理实现；本次以 Windows x64 为验收环境，不代表上游原作者发布了同名版本。代码继续维护在本 Fork 的 `feature/desktop-throw-animations` 分支。

新增默认大肥鱼的甩出、侧撞、撞顶、落地动作和 `><` 碰撞表情；贴地时恢复正常站姿，不持续蹲下。动画已参照原版待机配色校正。视频缓冲切换在新画面准备好后交接，避免将两个缓冲层同时显示；恢复末段在视频内部对齐形状后过渡至原版站姿。过渡片段加速、悬空循环原速。

沿用 0.3.8 的弹弓、分步物理、位置控制、占用锁和点播回执。外部明确点播动画具有显示优先级；用户开始拖动会取消被打断的点播。其他角色不套用大肥鱼的新视频。新增动画只增强桌面模式，网页宠物沿用上游显示；松手速度判定的修复通过共享物理逻辑作用于网页与桌面两端。

拿起与悬空动画从原始 1280×720 视频重新抠取透明轮廓，保留深色描边，并在缩放前按透明度预乘颜色，避免不可见的绿幕颜色混入轮廓。输出仍为 640×360，不额外羽化或锐化，保持原有帧数和动作时序，并参照上一版配色校准。沿用切换画面的持久画布与落地衔接，快速松手后再次抓取也会保留上一帧，等待原版画面交接。

配色进一步按原版待机与拖拽的多帧样本调整：轻微提亮蓝色头发暗部及较暗的轮廓，减轻压黑感；保留原有透明度数据，不对轮廓进行模糊或重新缩放。新动作的表情、发丝与阴影分布仍有生成素材差异，不声明与原版逐像素一致。

外轮廓较宽的暗线在内侧做轻微收细，保留最外层清晰边界及细发丝；不改变透明度、人物外形或画面尺寸。

甩出与飞行动画按实际水平速度决定镜像：向右保留原画面，向左水平翻转；接近竖直运动时保留已有方向，避免抖动。碰撞继续使用碰撞方向，恢复原版站姿时交还原有朝向。复用现有动画，不重新生成素材。

普通拖动松手时，将停顿计入最后 60 毫秒的均速；停住至少 60 毫秒或末段速度不足时原地放下，避免之前的移动峰值触发误甩。该判定位于两端共用的物理计算中，连续快速移动松手仍保留原有力度，原版双击拖动弹弓规则保持不变。

## 1.0.1 收尾人物形状

轻放及落地的恢复末段以原版待机首帧为参考，逐步对齐头型、脸部、裙摆、鞋底和尾巴；最终使用原版站姿画面转换后的颜色和原透明轮廓。落地修正在自然睁眼后开始，保留 `><` 碰撞表情。原版 BT.709 与定制片 BT.601 颜色矩阵在插入前转换，避免新增色差。

两段视频均保留 640×360、24fps、241 帧。前面的拿起、甩出和碰撞片段不变，原版叹气等动画的启动时机与播放进度也未调整；本次不宣称已经消除所有动作阶段差异。完整记录见仓库 `docs/ACCEPTANCE-1.0.1.md`。

## 安装与恢复

先退出 DSH，将发布附件 `dsh-pet-1.0.1.tgz` 下载到自己的电脑。使用 DSH 桌面应用自带 CLI 执行以下命令，路径替换成实际下载文件位置，profile 替换成自己使用的 profile：

```text
dsh plugin --profile desktop add ./dsh-pet-1.0.1.tgz
```

重新启动 DSH 后生效。该包使用原有 `dsh-pet` 名称，是替换安装，不能与官方同名插件重复加载。无需复制用户配置或粘贴 API Key；动画运行时不调用模型。

恢复官方 0.3.8：退出 DSH，执行 `dsh plugin --profile desktop add dsh-pet@0.3.8`，再启动 DSH。彻底移除插件可用 `dsh plugin --profile desktop remove dsh-pet`。这些命令不需要删除用户数据目录；不要为恢复动画去清空 DSH 会话或凭据。

官方商城升级可能覆盖改版。这里只声明已实际验证的兼容范围，不保证之后的官方版本可以直接覆盖安装自定义运行文件。

## 开发与验证

在仓库 `dsh-pet` 目录运行 `npm ci`、`npm run build`、`npm test`、`npm run test:motion`，完整打包检查用 `npm pack`。安装包包含构建后的宿主、客户端、运行壳和必要动画，不依赖开发者机器的目录或补丁安装记录。

`npm run preview:motion` 启动只读本机预览。它只提供仓库公开资源，支持视频范围读取，不连接真实 DSH、不读取用户会话或凭据。打开显示的预览地址后，可用 Playwright CLI 的 `run-code --filename ../tools/throw-preview/check-actions.js`、`check-handoff.js`、`check-physics.js` 和 `check-upstream.js` 验证动作、衔接及新版接口。各测试以当前预览页为入口，没有写死本机绝对路径。

本版验证构建、类型、代码风格、格式、素材健康、OpenAPI、项目及动作测试，并使用最终包内文件作桌面运行检查；当前结果见发布附件 `verification.json`。`1.0.0` 的安装、升级、回退及 DSH 0.2.1-rc.2 宿主验收为历史基线，不能当作 `1.0.1` 重新执行的结果。

桌面检查使用生产代码及实际窗口，宿主通信通过测试适配器转发到真实独立宿主路由。系统级鼠标操作被验收工具的透明窗口目标识别拦截，未计为通过；不能把这些结果说成完整人工手势验收。macOS、Linux、长期人工使用和全部真实跨屏动作尚未充分验证。正式发布不保证没有缺陷。素材条件见 [MEDIA-NOTICE.md](MEDIA-NOTICE.md)。
