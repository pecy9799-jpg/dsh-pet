## 1.0.6（2026-10-26，Windows 正式修订版）

本次公开发布合并以下 1.0.2～1.0.6 本机修正，公开下载由 1.0.1 升至 1.0.6。重点减少拿起、悬空扭动时的白灰残边及后侧卷发空隙亮点，不改动作时序、甩出方向、松手判定、碰撞素材和恢复末段。详见 [验收记录](ACCEPTANCE-1.0.6.md)。

- 用户定位到 60～67 帧后，离线逐帧对比发现后侧卷发内部空隙边界仍有白灰污染。此前为了保护衣服及头饰白色而填充全部内部孔洞，导致这部分头发内缘被排除；本次通过蓝色后发位置及颜色参照单独处理。
- 对卷发内缘局部重算颜色和少量透明度，避免仅染蓝使内侧发丝显粗。人物外缘 alpha 原样保留；在 alpha>4、16、32、128 的几何轮廓核对中，填充孔洞后的轮廓逐像素一致。主体内部、头饰与脸部、身体中部、尾巴区域和最终恢复参考保持一致。此版不再声称全部 alpha 与旧版一致。
- 使用同一规则处理整个悬空循环，并在两端平滑淡入淡出：修改范围为第 53～152 帧的局部卷发内缘；第 0～52 帧、第 153 帧起及碰撞素材逐字节不变。动作时序和代码不变。
- 固定局部阈值下，60～67 帧被检测的内缘白灰像素数由每帧 17～63 降至 0；该指标只针对已定位区域，不等于所有背景下均无边缘差异。实际 Electron 连续保持悬空，完成至少三个循环。

## 1.0.5（2026-10-26，本机中间版本，修正已合并至 1.0.6）

- 补修持续悬空扭动时短暂显现的发梢白灰亮点：上一轮要求当前像素仍偏蓝，会漏掉已接近中性白灰的污染像素；本次以邻近蓝色头发核心确认区域，补修已定位的第 59、60、61、110 帧窄外沿。
- 仅修改上述 4 帧的少量颜色像素及对应共享色度采样，其余 237 帧 YUVA 逐字节一致，全部 241 帧 alpha 一致；不改变轮廓、内部、动作、循环时序或碰撞素材。
- 实际 Electron 预览连续保持悬空，完成至少三个循环；录取到的发梢白点由约 RGB(201,210,209) 变为约 RGB(125,137,151)，不透明度保持 255。这是已定位亮点的证据，不代表所有背景下不存在任何边缘差异。

## 1.0.4（2026-10-26，本机中间版本，修正已合并至 1.0.6）

- 针对后侧长发残留的灰亮细边做局部颜色修正：以邻近不透明蓝色头发为参照，结合动作对齐的前后帧，按亮度差和饱和度稀释程度计算柔和权重。
- 修正限定在后侧长发窄外沿，最高局部颜色混合权重 65%；不动 alpha，不收缩、模糊或重新缩放发丝。241 帧透明通道、主体内部、头饰与脸部所在上方区域、身体中部、尾巴所在下方区域和最后 7 帧恢复参考已核对保持一致。动作代码与碰撞素材不变。
- 隔离 Electron 轻放、抛掷及打断播放采集 691 帧，无人物整帧消失；深浅背景同步对比已生成。这不表示所有实际桌面背景下的亮边均已完全消失。

## 1.0.3（2026-10-26，本机中间版本，修正已合并至 1.0.6）

- 补充处理拿起、悬空扭动时窄外沿内的不透明偏白像素；颜色参照来自相邻人物内部，并使用动作对齐的相邻帧稳定参照。再用五帧运动补偿中值参照降低短暂偏亮，不混合透明轮廓或整幅画面。
- 附加修正限定在填充内部孔洞后的外轮廓附近，避免把头饰镂空和衣服本来的白色当成外部白边。241 帧 alpha 完全不变，距不透明外轮廓至少 4.5 像素的主体内部 YUVA 保持一致，最后 7 帧恢复参考完全一致。
- 固定阈值统计中，悬空循环外沿偏亮中性像素的平均数由 10.40 降至 3.52；其中邻近深色内部的白色像素峰值由 16 降至 3，原版参考峰值也是 3。该检测仍可能包含正常白色细节，不能据此声称所有帧已与原版一致或真实桌面白边完全消失。
- 隔离 Electron 播放采集 693 帧，轻放、抛掷、打断测试均未出现人物整帧消失。碰撞素材、动作时间、甩出方向和松手判定代码不变；当时公开 GitHub 下载仍为 1.0.1。

## 1.0.2（本机中间版本，修正已合并至 1.0.6）

- 减少拿起与悬空素材半透明外沿的白色光边：仅处理比相邻不透明人物边缘异常偏亮、偏中性的半透明像素，以附近人物颜色替换部分偏白成分。
- 不模糊、不羽化、不收缩轮廓、不重新缩放；241 帧透明通道及主体内部 YUVA 平面保持一致，接回原版站姿的最后 7 帧逐字节不变。碰撞素材、动作时间与镜像逻辑不变。
- 全片按固定亮度、色度和边缘范围阈值统计，偏亮中性边缘像素由 32,813 降至 3,025，减少约 90.8%；该指标不是主观白边宽度或观感改善的百分比，也不意味着所有边缘与原版一致。

## 1.0.1（2026-10-24：收尾人物形状）

- 轻放和落地收尾逐步贴合原版待机首帧，统一头型、脸部、裙摆、鞋底及尾巴形状；末尾直接使用原版站姿参考的颜色转换结果与原透明通道。落地修正在自然睁眼后开始，保留碰撞 `><` 表情。
- 仅修改两段视频的恢复末段，保留 640×360、24fps、241 帧、动作分段和播放倍率；不调整松手判定、抛掷方向、原版动作启动时机或叹气播放进度。前面拿起、悬空及碰撞片段的解码颜色和透明度平面保持不变。
- 原版参考采用 BT.709，定制片采用 BT.601，插入前转换颜色矩阵；最终站姿透明通道与原版参考逐像素相同。该修正不代表整段 AI 动画与原作一致，叹气中途的表情和动作阶段差异仍需单独处理。

本版作为本 Fork 的 Windows 正式修订版发布，保留 `1.0.0` 及旧测试版附件。素材处理方法见 [处理记录](../prompts/throw-motion.md#101-收尾人物形状修正)。

验证：两段视频各 241 帧通过解码核对，修改起点前的 YUVA 平面逐字节不变；最终站姿透明通道与原版参考一致，非透明区域 RGB 平均通道差约为 1.16/255。20 项动作测试通过；最终隔离 Electron 预览采集 694 帧，无人物整帧消失；轻放、叹气及落地三种交接均能完成。以上不代替所有真实桌面手势或跨平台验证。

## 0.3.8-throw-motion.2（2026-10-24）

相对 `.1` 发布版，更新以下内容：

- 改善落地后恢复原版动作前的短暂消失：自定义动画使用持久画布保留已解码画面，等待原版画面就绪后交接。落地脚底偏移平滑恢复，小幅回弹不反复重置落地动作；快速再次拿起时保留上一画面。
- 重新从高清源片抠取拿起及悬空动画，减少头发、身体边缘的绿幕残留和发虚；轻微调整头发暗部、对比度及轮廓内侧粗重感，保留帧数和动作时序。后续校色与轮廓内侧修整不改变重新抠像后的透明度。
- 甩出及飞行姿态按实际水平速度翻转：向左甩朝左倾，向右甩朝右倾；接近竖直运动时保留方向，碰撞继续按撞击方向处理。
- 改善普通松手误甩：停住至少 60 毫秒，或松手前最后一小段速度不足时原地放下；正常快速甩出保留原有力度。该物理修复作用于网页与桌面两端。原版“双击后按住拖动”的弹弓仍保留，松手依然会向拉动的反方向弹出。
- 增加慢拖、停顿、减速、左右甩出、重复松手事件和弹弓保留的回归检查；同步安装包、源码、素材包、演示和校验值。

验证：项目测试 1025 项通过、1 项跳过，动作测试 20 项通过；隔离 Electron 预览中的 7 组指针处理流程通过。左右实际拖动路径通过速度估计并正确翻转；画面检查采集 700 帧，未发现整个人物消失帧。构建、类型、代码风格、格式、素材健康与 OpenAPI 检查以发布附件 `verification.json` 的结果为准。

测试在 Windows x64 进行，隔离预览不能代替所有真实桌面场景、macOS、Linux 和多显示器手势验证。AI 素材的头型、发丝、表情与阴影仍有原作差异。本版本继续作为 Prerelease 发布，旧版附件保留。
