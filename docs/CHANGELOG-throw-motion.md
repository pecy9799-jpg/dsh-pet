## 1.0.1（2026-10-24：收尾人物形状）

- 轻放和落地收尾逐步贴合原版待机首帧，统一头型、脸部、裙摆、鞋底及尾巴形状；末尾直接使用原版站姿参考的颜色转换结果与原透明通道。落地修正在自然睁眼后开始，保留碰撞 `><` 表情。
- 仅修改两段视频的恢复末段，保留 640×360、24fps、241 帧、动作分段和播放倍率；不调整松手判定、抛掷方向、原版动作启动时机或叹气播放进度。前面拿起、悬空及碰撞片段的解码颜色和透明度平面保持不变。
- 原版参考采用 BT.709，定制片采用 BT.601，插入前转换颜色矩阵；最终站姿透明通道与原版参考逐像素相同。该修正不代表整段 AI 动画与原作一致，叹气中途的表情和动作阶段差异仍需单独处理。

本版作为本 Fork 的 Windows 正式修订版发布，保留 `1.0.0` 及旧测试版附件。素材处理方法见 [处理记录](../prompts/throw-motion.md#101-收尾人物形状修正)。

验证：两段视频各 241 帧通过解码核对，修改起点前的 YUVA 平面逐字节不变；最终站姿透明通道与原版参考一致，非透明区域 RGB 平均通道差约为 1.16/255。20 项动作测试通过；最终隔离 Electron 预览采集 694 帧，无人物整帧消失；轻放、叹气及落地三种交接均能完成。以上不代替所有真实桌面手势或跨平台验证。

## 0.3.8-throw-motion.2（2026-10-24）

相对 `.1` 发布版，更新以下内容：

- 改善落地后恢复原版动作前的短暂消失：自定义动画使用持久画布保留已解码画面，等待原版画面就绪后交接。落地脚底偏移平滑恢复，小幅回弹不反复重置落地动作；快速再次拿起时保留上一画面。
- 重新从高清源片抠取拿起及悬空动画，减少头发、身体边缘的绿幕残留和发虚；轻微调整头发暗部、对比度及轮廓内侧粗重感，保留帧数和动作时序。后续校色与轮廓内侧修整不改变重新抠像后的透明度。
- 甩出及飞行姿态按实际水平速度翻转：向左甩朝左倾，向右甩朝右倾；接近竖直运动时保留方向，碰撞继续按撞击方向处理。
- 改善普通松手误甩：停住至少 60 毫秒，或松手前最后一小段速度不足时原地放下；正常快速甩出保留原有力度。该物理修复作用于网页与桌面两端。原版“双击后按住拖动”的弹弓仍保留，松手依然会向拉动的反方向弹出。
- 增加慢拖、停顿、减速、左右甩出、重复松手事件和弹弓保留的回归检查；同步安装包、源码、素材包、演示和校验值。

验证：项目测试 1025 项通过、1 项跳过，动作测试 20 项通过；隔离 Electron 预览中的 7 组指针处理流程通过。左右实际拖动路径通过速度估计并正确翻转；画面检查采集 700 帧，未发现整个人物消失帧。构建、类型、代码风格、格式、素材健康与 OpenAPI 检查以发布附件 `verification.json` 的结果为准。

测试在 Windows x64 进行，隔离预览不能代替所有真实桌面场景、macOS、Linux 和多显示器手势验证。AI 素材的头型、发丝、表情与阴影仍有原作差异。本版本继续作为 Prerelease 发布，旧版附件保留。
