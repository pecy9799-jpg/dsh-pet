## 已知限制

Windows 界面操作工具无法可靠识别透明置顶桌宠窗口，系统级鼠标操作被目标窗口检查拦截；该项未计为通过。上述桌面交互通过生产窗口中的 PointerEvent 注入完成，协议消息经过测试适配器转发，不能据此宣称所有真实系统鼠标路径或 DSH 跨进程通信细节都已完整覆盖。

当前验收在 Windows x64、DSH 0.2.1-rc.2 和实际双显示器几何下执行，但未穷尽全部跨屏动作。macOS、Linux、长期人工使用、所有第三方角色与所有 DSH 版本不在本次完整验证范围内。AI 源片的头型、发丝、表情和阴影仍有原作差异。原版双击拖动弹弓保留，松手向拉动反方向弹出是有意功能。

正式版表示本 Fork 对上述支持范围的发布判断，不保证零缺陷。机器路径、鉴权能力文件、私人日志及完整用户会话不随发布附件提供；结构化验证结果见 Release 的 `verification.json`。
