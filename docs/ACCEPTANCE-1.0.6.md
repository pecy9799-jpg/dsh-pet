# Windows 1.0.6 白边修订版验收记录

日期：2026-10-26。非官方 Fork，基于上游 0.3.8 / 本 Fork 1.0.1。原作：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。代码保留 MIT；角色动画含 AI 二创及原作站姿参考，素材允许开源使用、禁止商用。

## 发布范围

将本机 1.0.2～1.0.6 的连续修正合并公开发布，重点减少拿起、悬空扭动时的白灰残边及后侧卷发内部亮点。没有修改动作代码、播放时序、松手防误甩、方向翻转或碰撞素材；保留 1.0.1 的恢复站姿。

外沿修正仅调整颜色。最后一轮修正针对卷发内缘，联合调整颜色和少量透明度，避免直接染蓝导致发丝显粗。不能将早期版本“全部 alpha 不变”的结论套用到最终 1.0.6。

## 限制

实际桌面背景、缩放、显卡与播放状态可能影响边缘观感；本版不保证彻底消除所有白边，也不宣称整个 AI 动画与原作逐像素一致。macOS、Linux、长期运行和全部跨屏动作未充分验证。凭据规则检查不构成绝对无泄漏证明。本次仅发布插件 TGZ 与素材，不新增独立 Windows 桌宠应用 ZIP，也不发布到原作者 npm 包。
